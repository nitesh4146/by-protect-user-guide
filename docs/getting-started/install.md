# Install and first launch

## What you need

- An Android phone with a camera, microphone and motion sensors.
- At least **200 MB** of free storage. This is the default for **Minimum free storage**. Monitoring won't start with less.
- A mobile plan that can send SMS, so the app can text your contacts.
- A screen lock (PIN, pattern or biometric) is recommended if you plan to use [Lock device on SOS](../settings.md#lock-device-on-sos).

## Install

Install BY Protect using the link or file provided by BY Technology, then open it. The app is called **BY Protect** and has a blue shield icon.

![BY Protect app icon](../assets/logo.png){ width="96" }

## First launch

When you first open the app, the Dashboard shows **Set up required** in amber. This means some required permissions haven't been granted yet.

1. Tap **Set up required**, or the **Setup** tab at the bottom.
2. Allow each permission. See [Grant permissions](permissions.md).
3. Add at least one trusted person. See [Add emergency contacts](contacts.md).
4. Return to the Dashboard. The button now reads **Arm monitoring**.

!!! note "Bottom navigation"
    The bar at the bottom of the Dashboard has four tabs: **Dashboard**, **Contacts**, **Events** and **Setup**. Settings is the gear icon in the top-right corner of the Dashboard.
